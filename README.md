# MarketPulse-Intelligence
Le système surveille une sélection d'analyste sur X, extrait leurs thèses (Tweets longs, articles, analyses originales), enrichit les données avec les cours réels via yfinance et génère une synthèse structurée grâce à Gemini 2.5 Flash


Description :

Pipeline automatisé de collecte et d'analyse de données financières transformant le flux brut des réseaux sociaux en intelligence de marché exploitable.

Le système surveille une sélection d'analystes financiers sur X.com, extrait leurs thèses (Tweets longs, articles, analyses originales), enrichit les données avec les cours réels via yfinance et génère une synthèse structurée grâce à Gemini 2.5 Flash.

Points clés :

Architecture Serverless : Déploiement via Google Cloud Functions et Cloud Run.

Persistance NoSQL : Archivage structuré sur Google Firestore avec gestion de l'idempotence.

Intelligence Artificielle : Synthèse pragmatique axée sur les mécanismes techniques, les opportunités et la discipline de marché (gestion des risques et timing).

Dashboard Interactif : Visualisation en temps réel construite avec Streamlit.

Ce projet démontre une capacité à orchestrer des services Cloud complexes pour répondre à un besoin critique : filtrer le bruit médiatique pour se concentrer sur les fondamentaux et la progression à long terme.
